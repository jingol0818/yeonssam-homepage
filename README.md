# 연쌤 AI 연구소 홈페이지

강사 브랜딩 홈페이지입니다. **설치할 것도, 빌드할 것도 없습니다.**
`index.html` 파일 하나와 `assets` 폴더만 있으면 그대로 동작합니다.

---

## 1. 파일이 어떻게 생겼나

```
yeonssam-homepage/
├── index.html          ← 홈페이지 전체 (이 파일 하나가 사이트입니다)
├── README.md           ← 지금 읽고 있는 안내문
├── .nojekyll           ← GitHub Pages 설정 파일 (건드리지 마세요)
└── assets/
    ├── avatar/         ← 연쌤 캐릭터 (배경 투명 처리 완료)
    ├── blog/           ← 블로그 최신 글 썸네일 3장
    └── field/          ← 강의 현장 사진 3장 + 강의 슬라이드 1장
```

미리 보려면 `index.html`을 **더블클릭**하면 브라우저에서 바로 열립니다.

### 움직이는 부분

| 무엇이 | 어떻게 |
|---|---|
| 첫 화면 배경 | 종이에 잉크가 번지는 효과 (three.js 셰이더) |
| 숫자 | 스크롤해서 보이면 0부터 올라갑니다 |
| 출강 기관 | 좌우로 흘러갑니다. 마우스를 올리면 멈춥니다 |
| 각 섹션 | 화면에 들어올 때 부드럽게 나타납니다 |
| 카드·사진·버튼 | 마우스를 올리면 살짝 떠오릅니다 |

세 가지를 미리 대비해 두었습니다.

- **인터넷이 느리거나 three.js를 못 불러오면** 잉크 배경만 안 나오고 나머지는 그대로 동작합니다.
- **어떤 이유로든 등장 효과가 실패하면** 3초 뒤 모든 내용이 강제로 보이게 됩니다. 빈 화면이 되지 않습니다.
- **컴퓨터에서 '동작 줄이기'를 켠 분에게는** 움직임이 모두 꺼지고 내용만 보입니다.

## 2. 고치는 곳은 세 군데뿐입니다

`index.html`을 메모장이나 VS Code로 열면, 고칠 곳마다 **✏️** 표시가 붙어 있습니다.
`Ctrl + F`로 `✏️`를 검색하면 순서대로 찾아갈 수 있습니다.

| 무엇을 | 어디서 | 방법 |
|---|---|---|
| 검색에 나오는 문구 | 파일 맨 위 `<title>`, `<meta description>` | 문장만 바꿉니다 |
| 히어로 큰 문구 | `<h1>AI는<br>어렵지 않습니다</h1>` | 문장만 바꿉니다. `<br>`은 줄바꿈입니다 |
| 블로그 최신 글 3개 | `<!-- ✏️ 새 글을 올리면 -->` 아래 | 제목·날짜·주소·사진 파일명 |
| 출강 기관 추가 | `<div class="mq-track">` 안 | `<span class="org">기관 이름</span>` 추가. **같은 목록이 두 번 반복**되므로 두 곳 모두에 넣어야 끊기지 않습니다 |
| 사진 교체 | `assets/` 폴더 | **같은 파일명으로 덮어쓰면** 코드 수정 없이 바뀝니다 |
| 색 | `:root { }` 안의 `--g05` ~ `--g95` 8줄 | 이 8줄만 바꾸면 사이트 전체 색이 바뀝니다 |
| 잉크 배경 색 | 파일 아래쪽 `uInkA` / `uInkB` | 색 코드 두 개만 바꾸면 됩니다 |

### 아직 비어 있는 칸 하나

첫 화면 숫자 카드 중 **점선으로 표시된 "누적 강의 횟수"** 칸은 비워 두었습니다.
실제 횟수를 세어서 넣어주세요.

```html
<div class="stat todo" data-reveal data-delay="1"><b><span>000</span><span class="unit">회</span></b><span>누적 강의 횟수</span></div>
```

1. `000`을 실제 숫자로 바꾸고, 올라가는 효과를 원하면 그 `<span>`에 `class="count" data-to="180"` 을 붙입니다
2. `class="stat todo"`에서 **`todo`만 지웁니다** → `class="stat"`

`todo`를 지우면 점선 테두리가 사라지고 다른 카드와 똑같아집니다.

## 3. GitHub에 올려서 인터넷에 공개하기

### 처음 한 번만 하는 설정

1. [github.com](https://github.com)에 로그인합니다.
2. 오른쪽 위 **`+` → New repository**를 누릅니다.
3. **Repository name**에 `yeonssam-homepage`를 적고, **Public**을 선택한 뒤 **Create repository**를 누릅니다.
4. 다음 화면에서 **uploading an existing file** 링크를 누릅니다.
5. 이 폴더 안의 `index.html`, `README.md`, `.nojekyll` 파일과 `assets` 폴더를
   **한꺼번에 끌어다 놓습니다.**
6. 아래 **Commit changes** 버튼을 누릅니다.
7. 상단 메뉴 **Settings → Pages**로 갑니다.
8. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 두고 **Save**.
9. 1~2분 기다리면 주소가 나옵니다:
   `https://<내아이디>.github.io/yeonssam-homepage/`

### 이후 내용을 수정할 때

GitHub 저장소 화면에서 `index.html`을 클릭 → 오른쪽 **연필 아이콘(✏️)** → 고치고
맨 아래 **Commit changes**. 1분 뒤 사이트에 반영됩니다.

> `.nojekyll` 파일은 GitHub가 사이트를 임의로 가공하지 않게 막아줍니다. 지우지 마세요.

## 4. 문의 메일은 어떻게 동작하나

구글폼이 아니라 **강사 개인 메일로 직접 옵니다.**

방문자가 `강의 문의하기` 버튼을 누르면 메일 앱이 열리고
제목과 문의 양식(기관명·담당자·희망 일정·대상·인원·주제·기자재)이 **자동으로 채워집니다.**
방문자는 빈칸만 채워 보내면 됩니다.

**메일 주소를 바꾸려면** `Ctrl + F`로 `digitalyeonssam@naver.com`을 검색해
나오는 **5곳 전부**를 새 주소로 바꿔주세요.

> 참고: 회사 PC 등 메일 앱이 설정되지 않은 환경에서는 버튼이 반응하지 않을 수 있습니다.
> 그래서 문의 섹션 아래에 주소를 글자로도 적어 두었습니다.

## 5. 나중에 개인 도메인 연결하기

`yeonha.kr` 같은 주소를 쓰고 싶을 때 하면 됩니다. 서둘러 할 필요는 없습니다.

1. 도메인을 구입합니다 (가비아, 후이즈, Cloudflare 등)
2. 이 폴더에 **`CNAME`이라는 이름의 파일**을 만들고(확장자 없음), 안에 도메인만 한 줄 적습니다:
   ```
   www.yeonha.kr
   ```
3. 도메인 판매처의 DNS 설정에서 `CNAME` 레코드를 추가합니다:

   | 유형 | 이름 | 값 |
   |---|---|---|
   | CNAME | www | `<내아이디>.github.io` |

4. GitHub **Settings → Pages → Custom domain**에 도메인을 입력하고 Save
5. **Enforce HTTPS**에 체크합니다 (인증서 발급에 몇십 분 걸릴 수 있습니다)

## 6. 남은 할 일

- [ ] 누적 강의 횟수 입력 (위 2번 참고)
- [ ] **저서 3권 표지 사진**: 블로그에 없어서 넣지 못했습니다.
      `assets/books/` 폴더를 만들어 넣고, 저서 카드에 `<img>`를 추가하면 설득력이 크게 올라갑니다.
- [ ] **프로필 사진**: 현재 캐릭터 아바타로 대체해 두었습니다.
      실제 사진을 쓰실지, 아바타를 그대로 쓰실지 결정해 주세요.
- [ ] 블로그 최신 글 3개를 주기적으로 갱신 (한 달에 한 번이면 충분합니다)

### 사진에 대해 알아두실 점

강의 현장 사진 3장은 블로그에서 가져왔습니다. **수강생 얼굴이 모자이크 처리되어 있고
블로그 워터마크가 남아 있습니다.** 그래서 첫 화면이 아니라 강의 이력 섹션의
작은 카드로만 썼습니다. 워터마크 없는 원본이 있으면 같은 파일명으로 덮어써 주세요.

## 7. 디자인 규칙 (색을 바꾸실 경우)

수강생 중 어르신이 많은 점을 고려해 아래 기준으로 만들었습니다. 바꾸실 때 참고하세요.

- 본문 글자 **18px**, 행간 **1.8** (일반 사이트보다 큽니다)
- 버튼 터치 영역 **48px 이상**
- **밝은 초록을 넓게, 짙은 초록은 좁게**. 짙은 초록(`--g80`)은 버튼과 인용문 한 곳에만 씁니다
- 흰 글씨는 `--g80` 위에서만 사용 (명도비 7.9:1)
- `--g40`처럼 중간 밝기 초록 위에는 **글자를 얹지 않습니다** (명도비 2.1:1로 읽기 어려움)
