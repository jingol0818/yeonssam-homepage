## 3. 내 GitHub으로 가져오기

지금 이 저장소는 **강의 진행자 계정**에 있습니다.
강사님이 직접 고치고 배포하려면 본인 계정에 사본을 만들어야 합니다.

### 방법 A. 내려받아서 새로 만들기 (추천)

가장 단순하고, 완전히 강사님 것이 됩니다. 진행자가 따로 해줄 일도 없습니다.

1. https://github.com/jingol0818/yeonssam-homepage 접속
2. 초록색 **Code → Download ZIP**
3. 압축을 풀어 컴퓨터에 보관합니다. **여기가 앞으로 작업할 폴더입니다**
4. GitHub에서 오른쪽 위 **`+` → New repository**
5. 이름은 `yeonssam-homepage` (아무 이름이나 괜찮습니다), **Public** 선택 → **Create repository**
6. 다음 화면에서 **uploading an existing file** 링크 클릭
7. 압축을 푼 폴더 안의 `index.html`, `README.md`, `.nojekyll` 과 `assets` 폴더를
   **한꺼번에 끌어다 놓기** → 맨 아래 **Commit changes**
8. 상단 **Settings → Pages** → Source `Deploy from a branch`,
   Branch `main` / `/ (root)` → **Save**
9. 1~2분 뒤 주소가 나옵니다: `https://<내아이디>.github.io/yeonssam-homepage/`

> `.nojekyll` 은 점(.)으로 시작해서 파일 탐색기에서 안 보일 수 있습니다.
> 폴더 옵션에서 '숨긴 항목 표시'를 켜고 함께 올려주세요.
> 혹시 빠뜨렸더라도 사이트는 정상 동작합니다.

### 방법 B. 포크 (클릭 두 번)

저장소 화면 오른쪽 위 **Fork** → 내 저장소가 생기면
**Settings → Pages → Branch: main / (root) → Save**.

방법 A와 결과는 같지만, 내 저장소에 "forked from ..." 표시가 남습니다.

### 방법 C. 계정 이전

진행자가 **Settings → 맨 아래 Transfer ownership** 에서 넘겨줄 수도 있습니다.
다만 이렇게 하면 **진행자 계정에서는 저장소가 사라집니다.**
강의 샘플로 남겨둘 생각이라면 방법 A나 B가 낫습니다.

> 어느 방법이든 **Public(공개)** 이어야 합니다. GitHub Pages 무료 배포 조건입니다.
> 사이트에 들어가는 이메일·이력은 이미 블로그와 기존 홈페이지에 공개된 정보입니다.

### 가장 중요한 것: AI에게 규칙을 먼저 알려주기

AI에게 그냥 "예쁘게 고쳐줘"라고 하면 **십중팔구 디자인이 망가집니다.**

```

아래 규칙을 반드시 지켜서 수정해줘.

[보는 사람]
1) 강의를 섭외하는 공공기관 담당자. 이력·자격·문의 경로가 빨리 보여야 함
2) 강의를 듣는 시니어 수강생. 글자가 크고 화면이 밝아야 함

[색] 초록 8단만 쓴다. 새 색을 만들지 마.
--g05 #F1F7F3  --g10 #E2EFE7  --g20 #C9E0D2  --g40 #8FBBA1
--g60 #4E8E6D  --g80 #1F5C46  --g95 #14342A   보조색 --warm #A96F45

- 짙은 초록(g80, g95)은 버튼과 인용문에만. 큰 배경으로 쓰지 마

[글꼴] 제목은 Gowun Batang(명조), 본문은 Pretendard. 다른 글꼴 추가하지 마.

[가독성] 시니어 수강생이 보는 화면이라 이건 양보 못 함
- 본문 18px 이상, 행간 1.8
- 본문 명도비 7:1 이상

- 네온, 회로, 그라디언트 같은 흔한 "AI 사이트" 연출

- 등장 효과 3초 안전장치 유지
```

## 5. AI 없이 직접 고치기

`index.html`을 메모장이나 VS Code로 열면 고칠 곳마다 **✏️** 표시가 있습니다.
`Ctrl + F`로 `✏️`를 검색하면 순서대로 찾아갑니다.

| 무엇을 | 어디서 | 방법 |
|---|---|---|
| 검색에 나오는 문구 | 파일 맨 위 title, meta description | 문장만 바꿉니다 |
| 첫 화면 큰 문구 | `<h1>AI는<br>어렵지 않습니다</h1>` | `<br>`은 줄바꿈입니다 |
| 블로그 최신 글 3개 | `✏️ 새 글을 올리면` 주석 아래 | 제목·날짜·주소·사진 파일명 |
| 출강 기관 추가 | `<div class="mq-track">` 안 | `<span class="org">기관 이름</span>` 추가. **같은 목록이 두 번 반복**되므로 두 곳 모두에 넣어야 끊기지 않습니다 |
| 사진 교체 | `assets/` 폴더 | **같은 파일명으로 덮어쓰면** 코드를 안 고쳐도 바뀝니다 |
| 전체 색 | `:root { }` 안의 `--g05` ~ `--g95` | 이 8줄만 바꾸면 사이트 전체가 바뀝니다 |
| 잉크 배경 색 | 파일 아래쪽 `uInkA` / `uInkB` | 색 코드 두 개 |
| 메일 주소 | `digitalyeonssam@naver.com` | `Ctrl+F`로 찾아 **5곳 전부** 바꾸세요 |

### 비어 있는 숫자 칸 채우기

첫 화면 숫자 카드 중 **점선으로 표시된 "누적 강의 횟수"** 칸입니다.

```html
<div class="stat todo" data-reveal data-delay="1"><b><span>000</span><span class="unit">회</span></b><span>누적 강의 횟수</span></div>
```

1. `000`을 실제 숫자로 바꿉니다. 올라가는 효과를 원하면 그 `<span>`에 `class="count" data-to="180"` 을 붙입니다
2. `class="stat todo"` 에서 **`todo`만 지웁니다** → `class="stat"`

`todo`를 지우면 점선이 사라지고 다른 카드와 똑같아집니다.
숫자를 안 넣기로 했다면 이 `<div>` 한 줄을 통째로 지우면 3칸이 됩니다.

## 6. 바꾼 것을 인터넷에 올리기

### 가장 쉬운 방법 (파일 하나만 고쳤을 때)

내 GitHub 저장소 → `index.html` 클릭 → 오른쪽 **연필 아이콘(✏️)** → 고치기 →
맨 아래 **Commit changes**. 1분쯤 뒤 사이트에 반영됩니다.

### 사진까지 바꿨을 때

저장소 화면에서 **Add file → Upload files** → 바뀐 파일을 끌어다 놓고 **Commit changes**.
같은 파일명이면 자동으로 덮어씁니다.

### 반영이 안 되는 것 같으면

브라우저가 예전 파일을 기억하고 있을 수 있습니다. `Ctrl + Shift + R` (강력 새로고침)을 누르세요.

> `.nojekyll` 파일은 GitHub가 사이트를 임의로 가공하지 않게 막아줍니다. 지우지 마세요.

## 7. 개인 도메인 연결

`yeonha.kr` 같은 주소를 쓰고 싶을 때만 하면 됩니다. **서둘러 할 필요 없습니다.**
GitHub이 주는 주소도 영구히 살아 있고, 명함에 적어도 되고 QR로 만들어도 됩니다.

1. 도메인을 구입합니다 (가비아, 후이즈, Cloudflare 등)
2. 이 폴더에 **`CNAME`이라는 이름의 파일**을 만들고(확장자 없음), 안에 도메인만 한 줄 적습니다

   ```
   www.yeonha.kr
   ```

3. 도메인 판매처의 DNS 설정에서 레코드를 추가합니다

   | 유형 | 이름 | 값 |
   |---|---|---|
   | CNAME | www | `<내아이디>.github.io` |

4. GitHub **Settings → Pages → Custom domain**에 도메인을 입력하고 Save
5. **Enforce HTTPS**에 체크합니다. 인증서 발급에 몇십 분 걸릴 수 있습니다

## 8. 파일 구조

```
yeonssam-homepage/
├── index.html          ← 홈페이지 전체 (이 파일 하나가 사이트입니다)
├── README.md           ← 지금 읽고 있는 안내문
├── .nojekyll           ← GitHub Pages 설정 (건드리지 마세요)
└── assets/
    ├── avatar/         ← 연쌤 캐릭터 2종 (배경 투명 처리 완료)
    ├── blog/           ← 블로그 최신 글 썸네일 3장
    └── field/          ← 강의 현장 사진 3장 + 강의 슬라이드 1장
```

전체 용량 약 850KB. 이미지는 웹용으로 줄여 놓았습니다 (원본 8.7MB → 780KB).

### 사진에 대해 알아두실 점

현장 사진 3장은 블로그에서 가져왔습니다.
**수강생 얼굴이 모자이크 처리되어 있고 블로그 워터마크가 남아 있습니다.**
그래서 첫 화면이 아니라 강의 이력 섹션의 작은 카드로만 썼습니다.
워터마크 없는 원본이 있으면 같은 파일명으로 덮어쓰면 됩니다.

## 9. 알려진 제약

- **잉크 배경은 인터넷이 필요합니다.** three.js를 외부에서 불러오기 때문입니다.
  못 불러오면 배경만 안 나오고 나머지는 정상 동작합니다.
- **메일 버튼은 메일 앱이 설정된 환경에서만 열립니다.** 회사 PC 등에서는 반응이 없을 수 있어
  문의 섹션 아래에 주소를 글자로도 적어 두었습니다.
- **블로그 최신 글은 자동으로 갱신되지 않습니다.** 네이버 블로그가 외부에서 글 목록을
  가져가는 것을 막고 있어 손으로 3칸을 바꿔야 합니다. 한 달에 한 번이면 충분합니다.
- **누적 강의 횟수는 비어 있습니다.** 실제 숫자를 몰라 임의로 채우지 않았습니다.

## 10. 디자인을 바꿀 때 참고

수강생 중 어르신이 많은 점을 고려해 아래 기준으로 만들었습니다.

- 본문 글자 **18px**, 행간 **1.8** (일반 사이트보다 큽니다)
- 버튼 터치 영역 **48px 이상**
- **밝은 초록을 넓게, 짙은 초록은 좁게.** 짙은 초록(`--g80`)은 버튼과 인용문 한 곳에만
- 흰 글씨는 `--g80` 위에서만 (명도비 7.9:1)
- `--g40` 처럼 중간 밝기 초록 위에는 **글자를 얹지 않습니다** (명도비 2.1:1로 읽기 어려움)
- 섹션마다 다른 처리를 씁니다. 흰 라운드 박스 카드를 모든 섹션에 반복하면
  금방 "AI가 만든 사이트"처럼 보입니다
